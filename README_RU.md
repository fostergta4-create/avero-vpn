# AVERO VPN — Android demo 0.1

## Что уже заложено
- Нативное Android-приложение на Kotlin + Jetpack Compose.
- Экран входа (пока локальная демонстрационная проверка).
- Главный экран в палитре Midnight Emerald.
- 17 географических локаций Германии (пока демонстрационные точки, не реальные серверы).
- Избранное, история и экран статистики.
- Объявлен Android `VpnService` и вызов системного `VpnService.prepare()` для запроса разрешения.

## Важные ограничения демоверсии
Это НЕ рабочий VPN. Сервис `AveroVpnService` пока пустой: он не создаёт TUN-интерфейс и не передаёт трафик. Экран прямо сообщает о демонстрационном режиме. Счётчик трафика и таймер пока не подключены к сетевому интерфейсу и не являются реальными измерениями.

Вход по почте пока проверяется локально. Google Sign-In, подтверждение почты, серверная регистрация, пробный период и лимит 5 ГБ требуют backend/Firebase и должны быть добавлены до публичного релиза.

## Сборка APK
1. Установить Android Studio (актуальную стабильную версию).
2. Открыть папку `avero_vpn_android` как проект.
3. Дождаться Gradle Sync и загрузки зависимостей.
4. Выбрать Build → Build Bundle(s) / APK(s) → Build APK(s).
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Требуется Android SDK 35 и JDK 17. Если Android Studio предложит обновить Gradle/плагины, сначала согласовать версии, а не обновлять всё автоматически.

## Что нужно для настоящего VPN
- Арендованные VPN-узлы в Германии и конфигурации WireGuard.
- Backend API для аккаунтов, выдачи конфигураций и проверки подписки/пробного периода.
- Серверный учёт суммарного трафика 5 ГБ за 5 дней.
- Настоящий Google OAuth/Firebase Authentication и подтверждение email.
- Интеграция WireGuard Android library или собственного корректного VPN-туннеля.
- Проверка DNS, IPv6, kill switch, переподключения и утечек до релиза.

Города в списке — географические ориентиры для будущих точек присутствия. Они не означают, что серверы в этих городах уже существуют.
